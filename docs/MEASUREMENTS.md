# Измерения (симуляция)

## Допуски по задержке чтения (развёртка в нулевой модели памяти: `+sysdy=N` для CPU, `+dmady=N` для циклов, где шиной владеет FPGA; N в тактах 96 МГц = 10,4 нс)
| Потребитель | Допуск | Граница |
|---|---|---|
| Видеоядро (текст/экран) | ~2–3 такта | при 2 текст рисуется, при 4 нет |
| CPU без `WAIT_n` (с полутактовой задержкой выходов) | 9 тактов (94 нс) | сбой с 10 |
| Звуковой DMA | 11 тактов (~115 нс) | неверные данные с 12 |
| Копроцессор (первое чтение пачки) | 6 тактов (62 нс) | кадр неверен с 7; решено упреждающим чтением |
Одно чтение DMA занимает два цикла 16 МГц. Копроцессор читает список в последних 16 циклах строки, старший байт первым.

## Контроллер SDRAM (master)
- Доступ 7 тактов (73 нс): ACTIVE, READ/WRITE с авто-предзарядом на такте 2, данные на такте 6. Задержка чтения DMA ≤ 9 тактов, поток копроцессора 0–1 такта, CPU получает WAIT менее чем в 0,1% тактов.
- Модель SDRAM: 0 нарушений tRCD/tRC/tRFC; максимальный интервал между регенерациями 9,4 мкс (весь SoC), 17,8–52 мкс в юнит-тесте с окнами запрета регенерации.
- Юнит-тест: 4443 чтения (CPU- и DMA-подобные) плюс 600 чтений потока копроцессора, 0 расхождений.

## Тестовые образы (`tests` перечислены в `scripts/regress.py`)
| Тест | Что проверяет | Эталонный кадр |
|---|---|---|
| flos | баннер FLOS на 950 мс | golden/flos.png |
| sprites | 48 спрайтов на самых занятых строках | golden/sprites.png |
| audio | 4 канала, байты DMA против ожидаемых | (кадра нет) |

| planar4 | 4 битплоскости 320×200 | golden/planar4.png |
| tiles16 | расширенный тайловый режим 16×16, карта в VRAM `$70000` | golden/tiles16.png |

| sprites2 | 24 спрайта: высоты 16–64, отражение, движение | golden/sprites2.png |
| cpu_vram | CPU пишет/читает 512 байт VRAM (прямо и LDIR) | golden/cpu_vram.png |
Кадры `golden/*.png` сняты с эталонной сборки (`make ref`): то же ядро, идеальные асинхронные памяти, оригинальный захват блиттера и спрайтовый конвейер.
Эталон проверяет только путь памяти; соответствие оригинальному железу OSCA (в частности правка блиттера и полутактовая задержка выходов CPU) этим не доказано.
