## P1. Регрессия на ветке wip/sdram-iob-timing
- [ ] Звуковой DMA с копроцессором (`lc_audio`) даёт несколько неверных чтений (получен байт 0 вместо ожидаемого, например `0x606a`), хотя `DMALAT` показывает ≤ 10 тактов
      (порог 11). Подозрение: лишний такт латентности (IOB-захват + слот 8 тактов), возможное столкновение с упреждающим чтением/регенерацией. Не разобрано.
      Варианты: (a) выходить из состояния доступа на такте 6, как в master, а завершение чтения делать параллельно (учесть дубль чтения того же слова);
      (b) приоритет чтения DMA над упреждающим чтением и регенерацией; (c) если не получится — захват напрямую из пина на такте 6 (хуже для IOB, сверить с trce).
- [ ] После исправления: `make regress` на ветке целиком (с моделью SDRAM с задержками: ~15 мин на прогон на одном ядре), затем влить в `master`.
